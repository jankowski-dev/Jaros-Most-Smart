# Синхронная заливка слова при озвучке

Дата: 2026-09-15

## Цель

Заменить анимацию-эквалайзер на заливку слова цветом слева направо, синхронную с
озвучкой. В разделе теста скрывать слово случайными символами (вместо `???`) и
плавно раскрывать его при верном ответе.

## Область изменений

- `speech-service.js` — добавить отчёт о прогрессе воспроизведения.
- `app.js` — разделы чтения и теста.
- `styles.css` — стили заливки, удаление стилей эквалайзера.
- `index.html` — удаление разметки эквалайзера.

## 1. API прогресса озвучки

`speak(text, options)` принимает новый необязательный колбэк:

```js
speak(text, { isWord: true, onProgress: (fraction) => {} }) // fraction: 0..1
```

- **Yandex-путь** (`playAudio`): известны `audio.duration` и `audio.currentTime`,
  прогресс = `currentTime / duration` через событие `ontimeupdate`.
- **Браузерный путь** (`speakBrowser` и `fallbackSpeakText`): используется
  `utterance.onboundary` → `charIndex / text.length`. Если `onboundary` не
  поддерживается, прогресс оценивается по времени через `requestAnimationFrame`
  (длительность ≈ длина текста × мс на символ). Перед завершением
  вызывается `onProgress(1)`.

Существующий контракт `speak()` (Promise, резолвится по окончании) сохраняется.
Отсутствие `onProgress` ничего не ломает.

## 2. Контроллер заливки

Одна переиспользуемая функция для обеих секций:

```js
setFillBoundary(letterElements, fraction)
```

- Элементы с индексом `< fraction × N` получают класс `.filled`.
- Плавность обеспечивает CSS `transition: color` на буквах.

Возврат к исходному цвету: анимация `fraction` от `1` к `0` за ~600 мс через
`requestAnimationFrame` (зелёная волна «уезжает» вправо).

## 3. Раздел чтения

- Клик по слову → старт озвучки с `onProgress`, буквы закрашиваются мятным.
- По окончании озвучки → обратный ход заливки.
- Повторный клик во время озвучки → отмена и запуск заново.
- Удаляются `#audioVisualizer`, стили `.audio-visualizer` / `.visualizer-bar`,
  функции `hideVisualizer()`.

## 4. Раздел теста

- `showTestWord()`: вместо `???` рендерит случайные символы — смесь букв и
  знаков (например `#`, `%`, `@`, `К`, `7`, `&`), ровно по числу букв в слове,
  каждый в отдельном `<span>`.
- `playCurrentTestWord()`: та же мятная заливка по символам-заглушкам.
- При верном ответе символы по очереди слева направо плавно превращаются в
  правильные буквы (fade + scale, сдвиг ~60 мс на символ), затем переход к
  следующему слову.
- Удаляются `#testAudioVisualizer` и функция `hideTestVisualizer()`.

## 5. Цвет

Заливка — мятный `#8BBCB2` (совпадает с цветом правильных ответов).

## 6. Проверка

Запуск `npm start`, открыть `http://localhost:3000`. Без ключей Yandex озвучка
идёт через браузерный fallback — анимация работает в обоих режимах.
